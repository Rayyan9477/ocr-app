## 🎯 Quick Start Guide

### 1. Basic Search (Enhanced with Caching)

The search interface now automatically caches results for faster performance:

1. **Enter your search query** in the search box
2. **Results appear instantly** if previously searched
3. **Green cache badge** shows when results are cached
4. **Performance metrics** display search speed improvements

**Pro Tip**: Repeated searches are 3-5x faster thanks to intelligent caching!

### 2. Export Search Results

Export your search results in multiple formats:

1. **Perform a search** to get results
2. **Click the "Export" button** in the header
3. **Choose your format**: CSV, JSON, TXT, or PDF
4. **Toggle metadata inclusion** if needed
5. **Click "Export"** to download your file

**Available Formats**:
- **CSV**: Perfect for Excel and data analysis
- **JSON**: Structured data for applications
- **TXT**: Simple text format for documentation
- **PDF**: Professional formatted reports

### 3. Batch Search Mode

Process multiple queries simultaneously:

1. **Click the layers icon** (🏢) to enable batch mode
2. **Enter multiple search queries** in separate boxes
3. **Click "+ Add Query"** for more search terms
4. **Click "Search All"** to process all queries
5. **View combined results** from all searches

**Use Cases**:
- Searching for multiple patient names
- Looking for various medical terms
- Comparing different document sections
- Bulk data extraction

## 📊 Performance Dashboard

Monitor search performance and cache effectiveness:

### Accessing Performance Metrics
1. **Click the chart icon** (📊) in the search header
2. **View real-time metrics**:
   - **Cache Hit Rate**: Percentage of cached searches
   - **Cached Items**: Number of stored search results
   - **Memory Usage**: Cache memory consumption
   - **Utilization**: Cache efficiency percentage

### Cache Management
- **Clear Cache**: Remove all cached results
- **Warm Cache**: Pre-load popular searches
- **Monitor Performance**: Track search speed improvements

## 🔧 Advanced Features

### Smart Search Options

**Fuzzy Threshold**:
- **Lower values** (0.1-0.3): Exact matches only
- **Higher values** (0.4-0.8): More flexible matching
- **Use Case**: Adjust based on document quality

**Confidence Levels**:
- **High** (85%+): Most reliable results
- **Medium** (50-84%): Good quality matches
- **Low** (<50%): May require review

**Sorting Options**:
- **Relevance**: Best matches first
- **Confidence**: Highest quality first
- **Page**: Sequential document order

### Result Categories

**High Confidence** (Green Badge):
- Machine-printed text
- Clear, high-quality scans
- Standard fonts and formatting

**Medium Confidence** (Yellow Badge):
- Mixed quality documents
- Some formatting issues
- Partially clear text

**Low Confidence** (Red Badge):
- Poor quality scans
- Damaged documents
- Requires manual review

**Handwritten** (Blue Badge):
- Handwritten text detected
- May require additional verification
- Advanced OCR processing applied

## 🛠️ Troubleshooting

### Common Issues

**Slow Search Performance**:
- Check cache hit rate in performance dashboard
- Clear cache if utilization is high
- Warm cache with common search terms

**Export Problems**:
- Ensure search results are available
- Try different export formats
- Check browser download settings

**Batch Search Issues**:
- Verify all queries have content
- Reduce number of simultaneous queries if needed
- Check individual query results

**Cache Issues**:
- Monitor memory usage in performance dashboard
- Clear cache if memory usage is high
- Restart application if cache becomes unresponsive
